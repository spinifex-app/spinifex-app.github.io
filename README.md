# spinifex-app.github.io

The public website for the Spinifex iOS app, served by GitHub Pages at
https://spinifex-app.github.io

| Page | URL | Used by |
| --- | --- | --- |
| Support | https://spinifex-app.github.io/ | App Store Connect "Support URL", app Settings |
| Privacy policy | https://spinifex-app.github.io/privacy/ | App Store Connect "Privacy Policy URL", paywall, app Settings |
| Terms of use | https://spinifex-app.github.io/terms/ | Support page, app Settings |

Plain HTML with one shared stylesheet (`assets/site.css`), no build step. Edit a
page, merge to `main`, and GitHub Pages publishes it within a minute or two.

These URLs are linked from the app and App Store Connect, so don't rename the
folders. When the privacy policy changes, update its "Last updated" date.
